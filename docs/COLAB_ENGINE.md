# NAMMA SPACE — Remote GPU Reconstruction Engine & Research Evaluation

## 1. Google Colab GPU Runner Setup (Free T4 / Kaggle P100)

Running photogrammetry on a dedicated GPU allows enabling CUDA-accelerated feature extraction, GPU matching, and dense Multi-View Stereo (`patch_match_stereo`), yielding **$10\times$ to $20\times$ more 3D points** without laptop memory limits.

### Step-by-Step Launch Guide
1. Go to [Google Colab](https://colab.research.google.com) and create a **New Notebook**.
2. Click **Runtime** → **Change runtime type** → select **T4 GPU** (free tier).
3. In the first cell, install dependencies:
   ```bash
   !apt-get update -qq && apt-get install -y colmap ffmpeg
   !pip install -q fastapi uvicorn pyngrok open3d trimesh shapely pyproj opencv-python-headless
   ```
4. Copy `colab/engine_server.py` into Colab or run:
   ```python
   # Set your free ngrok auth token from https://dashboard.ngrok.com
   import os
   os.environ["NGROK_AUTHTOKEN"] = "your_ngrok_token_here"
   !python engine_server.py
   ```
5. Note the public URL generated by ngrok (e.g., `https://xyz.ngrok-free.app`).
6. In your local `namma/backend/.env`, set:
   ```env
   RECON_ENGINE_URL=https://xyz.ngrok-free.app
   ENGINE_API_KEY=optional_secret_token
   ```
7. Restart the Node backend server. The backend health check will automatically detect `mode: CUDA` and route heavy reconstruction jobs to the remote GPU!

## 2. Research Evaluation: Learned MVS & Novel View Synthesis

Can deep-learning 3D reconstruction models plug into Namma Space's architecture? Here is our technical evaluation across three leading paradigms:

| Method | Architectural Principle | GPU VRAM Required | Inference Time (60 frames) | Output Format | Web / Three.js Viewer Suitability | Recommendation for Namma Space |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **Depth Anything v2 (Metric)** | Monocular depth foundation model | $\sim 4$–$6\text{ GB}$ VRAM | $\sim 8$–$15\text{ seconds}$ | Depth maps per frame $\rightarrow$ fused point cloud / mesh | **High** (produces standard textured GLB mesh or point cloud directly viewable in Three.js) | **Recommended Phase 2 addition** for dense depth backfill on featureless walls. |
| **DUSt3R / MASt3R** | Dense stereo/multi-view uncalibrated pointmap regression without prior SfM | $12$–$16\text{ GB}$ VRAM (high peak) | $\sim 45$–$90\text{ seconds}$ | Dense point cloud (`.ply`) with confidence scores | **Medium-High** (point clouds render easily; meshing uncalibrated pointmaps can have noisy borders) | **Promising for difficult untextured corridors** where COLMAP SIFT features fail completely. |
| **3D Gaussian Splatting (3DGS)** | Radiance field optimization using 3D Gaussians | $8$–$12\text{ GB}$ VRAM | $3$–$8\text{ minutes}$ | `.ply` / `.splat` (3D Gaussians with covariance matrices) | **Specialized** (requires WebGL/WebGPU Gaussian Splatting shaders, does not produce standard collision meshes for navigation) | **Not recommended for BIM / Navigation**, but excellent for purely visual photorealistic walk-throughs. |

### Detailed Analysis

#### 1. Depth Anything v2 (Metric)
- **Why it fits:** It takes raw camera frames and estimates high-resolution metric depth per pixel. Unlike classical photogrammetry, it works even on blank, featureless walls.
- **Integration path:** Runs in Colab; unprojects depth maps to 3D points, filters outliers, and runs our existing `structural_shell.py` plane detector to close walls.

#### 2. DUSt3R (Dense Uncalibrated Stereo)
- **Why it fits:** Completely bypasses COLMAP feature matching. It regresses 3D pointmaps directly from image pairs and aligns them globally.
- **Limitation:** High VRAM footprint ($> 12\text{ GB}$) requires an A100 or T4 with small batch size ($30$ frames max).

#### 3. 3D Gaussian Splatting
- **Why it is distinct:** 3DGS produces stunning photorealistic imagery, but the output is an unstructured cloud of 3D ellipsoidal Gaussians. It does not provide explicit surface topology, watertight polygons, or floor boundaries required for floor plan extraction and A* robot/agent navigation.
